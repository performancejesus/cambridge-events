## 8. Бережный сбор (сделан первым)

### Что делает общий слой

| Правило | Как сделано |
|---|---|
| Одна и та же страница — не чаще раза в сутки | Кэш страниц `data/http_state.db` (таблица `pages`) + тела в `data/cache/pages/`; повторный запрос в течение 24 ч отдаётся из кэша, без сети |
| Пауза между запросами к одному сайту 5–10 с или по Crawl-delay | 6 с по умолчанию; 10 с для Junction, CPPF, Visit Cambridge, Visit West Norfolk, cus.org, Theatre Royal; 20 с для Cambridge Foodies (отвечал 429); Crawl-delay из robots.txt, если больше. Пауза общая для всех процессов (`BEGIN IMMEDIATE` в общей базе), поэтому два параллельных скрипта не удваивают частоту |
| Условные запросы | После суток — запрос с `If-None-Match` / `If-Modified-Since`; ответ 304 берётся из кэша |
| Повтор после ошибки — не чаще раза в сутки | Ошибочный ответ кэшируется на 24 ч; модуль получает `Deferred` и пропускает страницу до завтра, данные в базе не трогаются |
| Сайт начал закрываться | 403, 429, 5xx, заглушка бот-защиты (Sucuri, Cloudflare, «перезагрузка через 5 секунд») → пауза домена 24 ч; после паузы — сначала один запрос к главной, и только если она открылась — остальные страницы |
| Защита от перегруза | Не больше 250 сетевых запросов к одному домену в сутки (предохранитель) |
| robots.txt | Читается раз в сутки и кэшируется; `respect_ai_disallow` по-прежнему выключен |
| Журнал | `request_log`: время, сайт, адрес, модуль (`purpose`), результат (сеть / 304 / кэш / пропуск по паузе / запрет robots), статус |

Регрессионные тесты — `tests/test_polite_http.py` (кэш на сутки, условный запрос, ошибка → завтра, пауза домена и
проверка главной, общая пауза между процессами, 202 Skiddle — ошибка страницы, а не домена).

Модули переведены на слой: все коллекторы (`scripts/run_collectors.py`, `--slot` для расписания), перепроверка статусов,
обогащение, сверка продавцов, проверка ссылок выпуска (правило 7), `pipeline/domains.py` (теперь последовательно, без
параллельных потоков), «Не разобрано», детские провайдеры, курсы, профили мест, перепроверка ежегодных событий.

две недели до начала триместров (сентябрь, январь, апрель); в расписании этапа 8 — ежедневный прогон `--run`, который
