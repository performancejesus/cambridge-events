## 1. Cambridge Union и The Orator

**Что нашлось.**
- **Список событий.** Список https://cus.org/event («EventJet») — это записи WordPress типа `event_jet`. Их отдаёт открытый REST `https://cus.org/wp-json/wp/v2/event_jet` без токенов, robots.txt разрешает всё.
  - В REST есть только название и ссылка. Дата, уровень доступа и площадка — только на странице события.
  - Фильтры страницы дают точный список уровней доступа (8) и площадок (The Cambridge Union, The Orator, The Footlight Cellars).
- **Сейчас опубликованных событий 0.** REST отвечает `X-WP-Total: 0`, RSS `cus.org/event/feed` пуст, страница-пример `new-years-eve-at-the-orator` отвечает 404. Прошедшие события сайт снимает с публикации сам (плагин PublishPress Future), а Michaelmas ещё не выложен. Коллектор готов и начнёт приносить события, как только они появятся.
- **JSON-LD** на страницах — только организация (Yoast), событий в нём нет.
- **Termcard** (cus.org/whats-on/termcard) — вложенный журнал Issuu из картинок, текста нет. Сейчас там Easter 2026. Не разбираем.
- **The Orator's Cellar на Skiddle** — «No events to display». Площадки The Orator, The Orator's Cellar(s) и The Footlight Cellars добавлены синонимами одной площадки (Round Church Street, CB5 8AD), так что события Skiddle и cus.org склеятся.
- **The Orator в Visit Cambridge** — только карточка места, событий нет.
- **Особенность сайта.** cus.org отвечает 429 уже после десятка запросов с паузой 2 с, поэтому для него пауза 10 с.

**Доступ.**

| Метка EventJet | `access` | В выпуске |
|---|---|---|
| Open To The Public, Ticketed | open | как обычно |
| Members Only, Members & Cambridge Students | members | «только для членов Cambridge Union (членство — £370 в год)» со ссылкой на cus.org/membership |
| Life, Annual & Access Members Only | restricted | не берём: эти виды членства — только для нынешних и бывших студентов и сотрудников |
| All Staff & Students, Students Only, Staff Only | restricted | не берём |

**Членство для не-студентов** — только **Open (Members of the Public): £370 в год**.
- Life (£275 по осенней скидке вместо £315), Annual (£200) и Access (от £95) доступны только студентам, выпускникам и сотрудникам Cambridge и Anglia Ruskin.
- Гость члена клуба платит £25 на месте, только в день события, и места не гарантированы.
- В начале Michaelmas проходит **Open Period**: события открыты для всех бесплатно. Такие события придут с меткой «Open To The Public».
- Цена £370 читается со страницы членства при каждом сборе.

**Общее правило «Доступ к событию».**
- У события и у записи источника появились поля `access` / `access_note`.
- Коллектор может задать доступ явно (Cambridge Union). Иначе доступ определяется по однозначным фразам: «students only», «members only», «invitation only», «not open to the public».
- «Бесплатно для членов National Trust» — это цена, а не `members`.
- «Participation … by invitation only» (участники мастер-класса) — не ограничение для зрителей.
- Если источники расходятся, берётся самый открытый доступ.
- На всей базе ограничение нашлось только у одного события — «by invitation only» у мастер-класса, и оно оказалось про участников. Правило в основном нужно для Union и колледжей.

## 2. Кино — где идёт, оценка, описание (без ключа TMDB)

**Где идёт — только подтверждённое.**
- **Light Cinema Cambridge (S157).** Страница `thelight.co.uk/cinema/cambridge` — выбор кинотеатра через форму. Сама афиша живёт на поддомене `cambridge.thelight.co.uk`, и расписание на 2 недели (фильмы, event cinema, сеансы) страница берёт из открытого JSON `…/resource/services/miniguide/data.ashx`:
  - без токена, без входа, без сессии; параметр `d` — просто метка кэша; robots.txt разрешает всё;
  - по правилу брифа подключён;
  - трансляции (NT Live, Queen, Hadestown) и спецпоказы с Q&A становятся событиями, фильмы — строкой «где идёт».
- **Arts Picturehouse (S045)** — «Now Playing» и спецпоказы, как на этапе 6c. Сеансы по AJAX с XSRF-токеном не используем.
- **Vue** — закрыт, не обходим.
- **Крупный релиз без подтверждения кинотеатра** — «в широком прокате». Широкий = фильм есть в календаре крупных релизов mediamole.co.uk, куда попадают только широкие релизы. Числа копий в открытых данных нет.

**Оценка фильма (0–10).**

| Признак | Баллы |
|---|---|
| Просмотры статьи Wikipedia за 30 дней | 1 тыс. → 0, 300 тыс. и больше → 5 |
| Широкий прокат | +2 |
| Идёт в двух кинотеатрах | +1 |
| Местный повод: Q&A, трансляция, фестиваль, премьера | +2 |
| Повторный прокат | −1 |

- Отзывы критиков — только из открытых API: без ключа TMDB таких нет. Rotten Tomatoes и Metacritic не парсим.

**Описание.**
- Берётся краткое содержание статьи Wikipedia (REST `page/summary`: жанр, режиссёр, актёры). Модель пересказывает его своими словами.
- Статью ищем как «<название> (<год> film)», потом «(film)», потом поиском Wikipedia.
- У повторного проката ожидаемый год считается по юбилею: «The Others (25th Anniversary)» → 2001. Реставрация не может быть статьёй о новом фильме.
- У каждого полного пункта о фильме редактор видит, по какой статье взяты факты и где он идёт.

**В письме.**
- 2–4 главных фильма окна — полными пунктами (кандидаты `F…`, лучшие 8 по оценке).
- Остальные релизы — компактной строкой, как раньше, но с пометкой, где идёт: «Other Mommy (The Light)».
- Спецпоказы — пунктами рубрики.

## 8. Замечания

- **Cambridge Union** — проверить после публикации Michaelmas termcard. Коллектор готов, но на живых страницах событий его ещё не видели: страниц сейчас нет, в архиве их не нашлось (web.archive.org недоступен из среды).
- **Фильмы без подтверждённого кинотеатра** (крупные релизы 16 октября) помечены «в широком прокате». Расписание Light на 16-е ещё не выложено: оно появляется примерно за неделю.
- **Описание фильма берётся из Wikipedia.** Для повторного проката статью подбирает правило; у каждого фильма редактор видит, по какой статье взяты факты («тот ли фильм?»). «Dracula (4K Restoration)» сопоставлен с фильмом Hammer 1958 года — это правдоподобно, но не наверняка.
- **«Также в программе: Professor Josephine Crawley Quinn»** у лекции в St John's. Проверка «исполнитель назван в тексте» дописала имя латиницей, потому что в описании оно было кириллицей. Это старое поведение, в работу этапа не входило.
